# Block 10 – Übungen

## Ziele
- Projektziel: Du gibst JSON aus und baust eine mini-API ohne DRF.

## Aufgaben
- Aufgabe A: Endpoint `/api/posts/` der eine Liste der Posts als JSON liefert (id, title, author).
- Aufgabe B: Endpoint `/api/posts/<id>/` der Details liefert oder 404.
- Aufgabe C: Füge einfache Paginierung hinzu (`?page=1&size=10`).

## Bonus
- Skizziere, was DRF dir hier erleichtern würde (3 Punkte).

## Abgabe/Check
- Code läuft lokal (`python manage.py runserver`).
- Relevante Änderungen sind committet.
- Kurze Notizen zu Learnings (2–5 Stichpunkte).
