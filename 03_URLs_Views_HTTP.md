# Block 03 – Übungen

## Ziele
- Projektziel: Du kannst URL-Patterns schreiben und GET/POST unterscheiden.

## Aufgaben
- Aufgabe A: Erstelle eine View `/ping/`, die JSON `{ 'status': 'ok' }` liefert.
- Aufgabe B: Erstelle eine View `/echo/`, die bei GET einen Parameter `msg` ausliest und zurückgibt.
- Aufgabe C: Erstelle eine POST-View `/submit/`, die ein Feld `name` aus `request.POST` liest und bestätigt.

## Bonus
- Implementiere eine Klassenbasierte View (CBV) für `/ping/` und vergleiche den Codeumfang.

## Abgabe/Check
- Code läuft lokal (`python manage.py runserver`).
- Relevante Änderungen sind committet.
- Kurze Notizen zu Learnings (2–5 Stichpunkte).
