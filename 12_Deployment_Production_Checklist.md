# Block 12 – Übungen

## Ziele
- Projektziel: Du kennst die Schritte von Dev zu Production und kannst eine Checkliste anwenden.

## Aufgaben
- Aufgabe A: Stelle `DEBUG=False` und setze `ALLOWED_HOSTS` (lokal testbar).
- Aufgabe B: Erzeuge `SECRET_KEY`/Umgebungsvariablen-Setup (Dokumentation).
- Aufgabe C: Sammle Static Files mit `collectstatic` (in einem lokalen Ordner).
- Aufgabe D: Schreibe eine Deployment-Checkliste (mind. 10 Punkte) inkl. DB, Security, Static, Backups.

## Bonus
- Skizziere ein Setup mit Gunicorn + Nginx (oder ASGI + uvicorn) in 5–8 Stichpunkten.

## Abgabe/Check
- Code läuft lokal (`python manage.py runserver`).
- Relevante Änderungen sind committet.
- Kurze Notizen zu Learnings (2–5 Stichpunkte).
