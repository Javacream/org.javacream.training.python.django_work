# Block 07 – Übungen

## Ziele
- Projektziel: Du nutzt Django Admin produktiv und passt Listen/Formulare an.

## Aufgaben
- Aufgabe A: Registriere `Author`, `Post`, `Tag` im Admin.
- Aufgabe B: Passe `PostAdmin` an: `list_display`, `search_fields`, `list_filter`.
- Aufgabe C: Zeige im Post-Admin auch den Author-Namen und Tag-Anzahl an (method field).

## Bonus
- Füge `readonly_fields` oder `prepopulated_fields` hinzu (falls sinnvoll).

## Abgabe/Check
- Code läuft lokal (`python manage.py runserver`).
- Relevante Änderungen sind committet.
- Kurze Notizen zu Learnings (2–5 Stichpunkte).
